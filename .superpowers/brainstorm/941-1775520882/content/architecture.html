Flux de données — Render Pipeline
1. User clique Render
→
2. POST /api/render
{compositionId, props, format}
→
3. spawn npx remotion render
child_process
→
4. SSE progress stream
GET /api/render/progress
→
5. MP4 → /public/renders/
+ download link

→
2. POST /api/ai/generate
streaming response
→
3. Claude → JSON props
{template, titre, couleurs…}
→
4. Preview live mis à jour
Remotion Player re-render
